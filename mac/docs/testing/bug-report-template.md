# Bug report template

Copy this into an email or a message. One problem per report. Plain words are fine.

```text
Your name:
Version: the name of the installer file you used (for example OpenFrame-Studio-0.1.0-internal-028d8b6.exe)

What were you doing? (steps, in order)
  1.
  2.
  3.

What did you expect to happen?

What happened instead?

How bad is it? (choose one)
  [ ] I lost some of my writing
  [ ] A project is broken and will not open right
  [ ] My work did not come back after a crash, or a restore or update failed
  [ ] The AI changed my project on its own
  [ ] My private notes showed up where they should not
  [ ] Something else: I could not finish what I wanted, it was confusing, slow or ugly, or it is a wish

Does it happen every time, sometimes, or just once?

Screenshot, if you can: attach it.
Exported logs, if you can: attach them (see "How to send logs").
```

## For the person collecting reports

| Field | Fill in |
|---|---|
| Report number | Next number in the tracking sheet |
| Severity | After reading, using the classes in the [triage page](pilot-kit/triage.md) |
| Type | Defect, installation restriction, idea, question |
| Reproduced by | Name and date, or "not reproduced" |
| Cause | The file and function once known |
| Fix | Commit and test name |
| Checked again by | Reporter and date, in the build number |
