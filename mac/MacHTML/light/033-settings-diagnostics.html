Diagnostics
A diagnostics bundle helps the team find a problem. It never contains your project text. You choose where it is saved and whether to send it.

What the bundle includes

manifest.json, List of every file in this bundle, what it contains and its SHA-256 checksum. (2 KB)summary.json, OpenFrame version, Windows version, architecture, distribution channel and database schema versions. (779 bytes)errors.json, Error codes from recent logs, with how often and when they occurred. (412 bytes)timings.json, How long slow or failed operations took, by operation name. (119 bytes)log-tail.txt, The most recent log entries, rebuilt from fixed messages, operation names, error codes and numbers only. (427 bytes)ai-status.json, Offline AI status: available or not, bundle check, engine state and component versions. No folders or file paths. (1 KB)
