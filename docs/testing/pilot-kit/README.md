# Pilot kit (Windows and Mac)

What a team member needs for the 3-day pilot. Plan: [internal test plan](../internal-test-plan.md).

1. [Install note](install-note.md): install, first start, download the AI. It ends with a short note for the owner.
2. [Daily plan](daily-plan.md): what to try on each of the 3 days.
3. [How to send logs](how-to-send-logs.md): export the diagnostics and AI report.
4. [Bug report template](../bug-report-template.md): one problem per report.
5. [Triage](triage.md): for the owner, how reports are sorted and tracked.

After the pilot: [freeze steps](../../release/w10-freeze-steps.md).

Mac checks that only a person can do (the test Mac had a locked screen): record a voice note in the Idea Vault (allow the
microphone when macOS asks, then play it back), drag a moodboard note and reorder storyboard panels by dragging, and walk
each workspace with the Tab key.
