6 · Pagination rules (all exports)

  • Content flows by measured height; no absolute positioning for flowing content; sections expand; optional sections leave no gap.
  • Section headings stay with their first content; headings are never the last element of a page.
  • Table headers (and the table title) repeat on every page; rows, cards, callouts and figures never split; long tables continue at row boundaries.
  • Long text wraps; rows grow; nothing is clipped, truncated or ellipsised; images keep aspect ratio.
  • Avoid stray single rows, orphan headings, pages with only a stray item; the renderer moves the last two rows together when one row would be stranded.
  • Footer and page counter are page furniture drawn in the margin and are identical on every page.
