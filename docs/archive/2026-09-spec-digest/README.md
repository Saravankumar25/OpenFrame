# Specification digests (historical)

Dense summaries of the base specifications, written for implementers. They are **derived and never authoritative**:
the full text in [../specs/](../specs) wins, then Accepted ADRs ([register](../adr/README.md)).

Known staleness (2026-10-05): the digests were written before ADR-0007 and ADR-0013 and before the Revision 1
specification. Their LAN content (`collaboration.md`, and LAN passages in `fsd-part1.md`, `fsd-part2.md`, `prd.md`,
`security.md`, `ux.md`) is **superseded** and must not be implemented. The AI digest predates the single-model
profile. Revision 1 topics (production numbers, page breaks, custom elements, themes, DOOD, schedule timeline,
expanded call sheets, Planned/Actual budget) are not in any digest.

Refresh the digests only when a milestone needs one; otherwise read the specification itself.
