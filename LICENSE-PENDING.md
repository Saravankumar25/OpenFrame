# License: NOT YET SELECTED

> **Release blocker.** OpenFrame Studio does not have an open-source license yet.
> Until one is selected and committed, **no license is granted** for this code, and
> no public release, installer or binary may be distributed.

## Status

| Item | State |
|---|---|
| Product model | Free / open-source (Engineering Package Index, locked decisions) |
| License identifier | **Not selected.** The Engineering Package Index §7 lists it as an explicit open decision ("MIT, Apache-2.0, GPL-family, etc."). |
| Placeholder in manifests | `Cargo.toml` → `license = "LicenseRef-OpenFrame-Pending"`; `package.json` files → `"SEE LICENSE IN LICENSE-PENDING.md"` |
| Release automation | `scripts/release-validate.mjs` **fails closed** while this file exists or while any manifest still carries the placeholder. `.github/workflows/release.yml` builds nothing unless that gate passes. |

No license has been chosen, and nothing in this repository should be read as a choice.
Engineers and agents must not pick one. The decision belongs to the project owner.

## What the decision must consider (inputs, not a recommendation)

- **Third-party obligations.** `THIRD_PARTY_LICENSES.md` (generated by `npm run licenses`) lists every shipped
  dependency. Currently none are copyleft or unknown. Five crates are MPL-2.0 (file-level copyleft, reached
  through Tauri and `directories`): `cssparser`, `cssparser-macros`, `dtoa-short`, `selectors` and `option-ext`.
  Unmodified use of these is compatible with any common outbound license.
- **Local AI artifacts.** Model and runtime redistribution has its own notices (Local AI Runtime spec §17).
  The license of the `llama.cpp` sidecar and of the selected Qwen GGUF must be verified per artifact. These
  artifacts are downloaded after install, not bundled, but OpenFrame's distribution endpoint still redistributes them.
- **Contributions.** Whether contributions need a DCO sign-off or a CLA depends on the chosen license.
- **Patent grant.** Some candidate licenses include an explicit patent grant and some do not.

## Steps once a license is selected

1. Add the license text as `LICENSE` (or `LICENSE-MIT` + `LICENSE-APACHE` for a dual license).
2. Replace `license = "LicenseRef-OpenFrame-Pending"` in the root `Cargo.toml` `[workspace.package]` with the SPDX identifier.
3. Replace `"license"` in `package.json` and `apps/desktop/package.json` with the SPDX identifier.
4. If needed, add the identifier to the `[licenses] allow` list in `deny.toml` (first-party crates are ignored there because they are `publish = false`).
5. Update `README.md` ("License"), `CONTRIBUTING.md` (sign-off policy) and `docs/engineering/24-windows-packaging-updater.md` (installer license page).
6. Delete this file.
7. Run `node scripts/release-validate.mjs --report-only` and confirm that "Open-source license selected" now passes.
