# License: end-user agreement not yet written

> **Release blocker.** OpenFrame Studio is a paid, closed-source product (owner decision 2026-10-06, ADR-0018).
> No open-source license will be chosen. Until the end-user license agreement is written, approved and committed,
> **no license is granted** for this code, and no public release, installer or binary may be distributed.

## Status

| Item | State |
|---|---|
| Product model | Paid app with a 7-day free trial, no credit card to start (ADR-0018). Supersedes "Free / open-source" in the Engineering Package Index. |
| License | **End-user license agreement (EULA) not yet written.** The owner writes or approves the text. Counsel review is a manual task in `docs/implementation/owner-decisions.md`. |
| Placeholder in manifests | `Cargo.toml` has `license = "LicenseRef-OpenFrame-Pending"`; `package.json` files have `"SEE LICENSE IN LICENSE-PENDING.md"` |
| Release automation | `scripts/release-validate.mjs` **fails closed** while this file exists or while any manifest still carries the placeholder. `.github/workflows/release.yml` builds nothing unless that gate passes. |

Engineers and agents must not write the agreement or pick a license. The decision belongs to the project owner.

## What the agreement must consider (inputs, not a recommendation)

- **Third-party obligations.** `THIRD_PARTY_LICENSES.md` (generated by `npm run licenses`) lists every shipped
  dependency. Currently none are copyleft or unknown. Five crates are MPL-2.0 (file-level copyleft, reached
  through Tauri and `directories`): `cssparser`, `cssparser-macros`, `dtoa-short`, `selectors` and `option-ext`.
  Unmodified use of these is compatible with a closed-source product. The shipped notices page must list them.
- **Local AI artifacts.** Model and engine redistribution has its own notices (Local AI Runtime spec section 17).
  The license of the `llama.cpp` engine, of Gemma 3 1B Instruct (Gemma Terms of Use, redistribution rules in
  `docs/engineering/23-release-migration.md` section 7) and of BGE small English v1.5 must be verified per artifact.
  Model weights are downloaded after install, but OpenFrame's distribution endpoint still redistributes them.
- **Three channels.** The Microsoft Store and the Mac App Store each have a standard license terms page. The agreement for
  the Windows installer must say what happens at the end of the trial and what a purchase covers.
- **Refunds and the trial.** The agreement and the store listings must say the same thing (ADR-0018, still open: price and refunds).

## Steps once the agreement is approved

1. Add the agreement text as `LICENSE` and show it in the Windows installer license page and on the website.
2. Replace `license = "LicenseRef-OpenFrame-Pending"` in the root `Cargo.toml` `[workspace.package]` with the approved identifier.
3. Replace `"license"` in `package.json` and `apps/desktop/package.json` with the same identifier.
4. If needed, adjust the `[licenses]` section of `deny.toml` (first-party crates are ignored there because they are `publish = false`).
5. Update `README.md` ("License") and `docs/engineering/24-windows-packaging-updater.md` (installer license page).
6. Delete this file.
7. Run `node scripts/release-validate.mjs --report-only` and confirm that the license check now passes. Update that check's wording from "End-user license agreement in place" to "End-user license agreement in place".
